# SoloPup open-source tools

## SoloPup Subtitle Studio · 字幕工作台

[Source / 源码](https://github.com/OakcoderX/solopup-subtitle-studio) · [中文介绍](https://oakcoderx.github.io/solopup-subtitle-studio/zh.html) · [Preview download / 预览下载](https://github.com/OakcoderX/solopup-subtitle-studio/releases/tag/v2.0.0-rc.5) · [Free tools / 免费工具](https://oakcoderx.github.io/solopup-subtitle-studio/resources.html)

An MIT-licensed local workspace for SDH accessibility-caption review and English subtitles for Chinese-language audio. Compare text and timing against video, preserve review decisions, and export separate SRT or ITT tracks. Existing paired-SRT manual review requires no AI account; optional cloud processing uses your provider account and may incur charges.

采用 MIT 许可的本地字幕工作台，支持 SDH 无障碍字幕审校、中文配音逐屏英译、中英双轨对照和分轨导出。已有中英 SRT 可不配置 AI 接口进行本地审校；可选云端处理需自己的服务商账户，可能收费。

[![Actual bilingual-review interface with synthetic demo data](https://oakcoderx.github.io/solopup-subtitle-studio/screenshots/bilingual-review.jpg)](https://oakcoderx.github.io/solopup-subtitle-studio/walkthrough.html)

**Public preview v2.0.0-rc.5.** Human audiovisual review is required. The screenshot shows the real app with synthetic imported text and AI-generated demo artwork, not a transcription/translation benchmark. macOS has been locally tested; Windows/Linux manual acceptance is incomplete. Bilingual controls currently use Chinese.
